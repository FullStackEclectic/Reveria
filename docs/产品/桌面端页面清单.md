# 桌面端页面清单

## 页面设计原则

Reveria 桌面端是创作工作台，不是官网。打开应用后应该直接进入工作区和项目，而不是宣传页。

导航建议：

```text
工作台
项目
客户
品牌库
素材库
模板
生成历史
点数
设置
```

## 1. 登录页

目标：

- 完成登录和注册。

模块：

- 邮箱或手机号登录
- 第三方登录预留
- 工作区选择
- 错误提示

## 2. 工作区首页

目标：

- 让用户快速进入最近工作。

模块：

- 最近项目
- 待处理任务
- 最近生成结果
- 常用模板
- 点数余额
- 创建项目按钮

## 3. 项目列表页

目标：

- 管理所有客户项目。

模块：

- 项目搜索
- 状态筛选
- 客户筛选
- 最近更新时间
- 项目消耗点数
- 创建项目

## 4. 项目详情页

目标：

- 承载一次客户交付的完整流程。

模块：

- 项目 brief
- 品牌上下文
- 参考素材
- 创意方向
- 生成任务
- 交付版本
- 点数消耗
- 修改记录

核心操作：

- 分析 brief
- 生成创意方向
- 生成封面
- 生成脚本
- 生成分镜
- 上传素材
- 导出交付包

## 5. 无限画布页

目标：

- 对比、整理和标注生成结果。

功能细节 (已在当前版本实现)：

- 图片与备注卡片排列，支持自由拖拽位置和大小
- 画布元素选中、层级调整、复制与删除快捷键
- 文本卡片样式自定义（标题、正文、颜色、尺寸）
- 支持将工作流生成输出一键直接加入画布
- 支持将画布导出为 SVG 矢量快照、Markdown 和 JSON
- 支持多画板管理：封面候选、脚本分镜、交付清单

## 6. 客户列表页

目标：

- 管理工作室服务的客户。

模块：

- 客户搜索
- 行业筛选
- 项目数量
- 最近项目
- 创建客户

## 7. 客户详情页

目标：

- 查看客户长期资料和历史项目。

模块：

- 客户基础信息
- 品牌库
- 历史项目
- 历史素材
- 客户偏好
- 备注

## 8. 品牌库页

目标：

- 管理客户品牌记忆。

模块：

- logo
- 色板
- 字体
- 视觉关键词
- 文案口吻
- 禁用词
- 历史案例
- style_prompt

核心操作：

- 上传品牌素材
- AI 分析品牌风格
- 人工确认风格
- 应用到项目

## 9. 素材库页

目标：

- 管理上传素材、生成素材和导出素材。

模块：

- 素材网格
- 类型筛选
- 项目筛选
- 客户筛选
- 上传
- 下载
- 删除

## 10. 模板页

目标：

- 让用户选择高频工作流。

模板：

- 客户 brief 分析
- 品牌风格提取
- 三套创意方向
- 小红书封面批量生成
- 短视频脚本和分镜

## 11. 生成历史页

目标：

- 查看所有 AI 任务和结果。

模块：

- 任务列表
- 状态筛选
- 类型筛选
- 点数消耗
- 失败原因
- 重试入口
- 结果跳转

## 12. 点数页

目标：

- 让用户理解余额和消耗。

模块：

- 当前余额
- 本月消耗
- 项目消耗排行
- 点数流水
- 充值入口
- 套餐信息

## 13. 设置页

目标：

- 管理个人和工作区设置。

模块：

- 个人资料
- 工作区信息
- 成员管理与邀请 (支持邮箱邀请、待加入状态、以及每日/每月积分额度强校验)
- 审计日志页面 (展示补点、扣点、成员变更、模板发布和任务结算详情)
- 权限与套餐
- 缓存清理
- 本地导出目录
- 通知设置

## 任务抽屉

很多生成任务可以用右侧抽屉承载，而不是跳转页面。

抽屉内容：

- 任务输入
- 品牌上下文
- 参考素材
- 输出数量
- 预估点数
- 预计耗时
- 开始生成

## 结果卡片

生成结果统一用结果卡片展示。

字段：

- 预览
- 任务类型
- 使用模板
- 点数消耗
- 创建时间
- 收藏
- 重试
- 应用到项目
- 导出

## MVP 页面优先级

P0：

- 登录页
- 工作区首页
- 项目列表页
- 项目详情页
- 客户列表页
- 品牌库页
- 生成历史页
- 点数页

P1：

- 素材库页
- 模板页
- 无限画布页 (已完成)
- 设置页 (已完成，包含审计日志与成员邀请)

P2：

- 客户门户与审批页 (已完成：支持项目 project_shares 客户免登录审批与外部评论)
- 高级画布页
- 插件页
- 本地 worker 设置页
