# MVP需求清单

## MVP 目标

MVP 的目标不是一次性做成 Lovart、LibTV 和 Canva 的集合，而是验证一个核心假设：

```text
中小型传媒工作室愿意把客户项目、品牌资产、AI 生成和点数消耗放进 Reveria 里统一管理。
```

因此第一版必须能完成真实项目闭环：

```text
创建客户
  -> 建立品牌库
  -> 创建项目 brief
  -> 生成文案和视觉方向
  -> 生成封面或海报
  -> 查看点数消耗
  -> 保存生成历史
  -> 导出交付素材
```

## 用户角色

- 工作室老板：关注成本、毛利、成员额度和客户交付。
- 项目负责人：关注项目进度、品牌一致性、版本和审批。
- 内容创作者：关注文案、封面、脚本、分镜和素材生成。
- 设计师：关注画面可控、参考图、尺寸、导出和精修。
- 管理员：关注上游模型、点数、套餐、异常调用和退款。

## P0 功能

P0 是第一版必须具备的闭环能力。

- 用户登录
- 工作区
- 客户管理
- 项目管理
- 品牌资料库
- 素材上传
- 文案生成
- 图片生成
- 生成历史
- 点数余额
- 点数预估
- 点数扣减
- 任务失败退款
- 基础 Admin Console
- 上游模型配置

## P1 功能

P1 是第一版发布后应尽快补齐的能力。（以下能力均已提前在当前版本中实现）

- 多成员协作 (已实现：支持成员每日/每月额度强校验、邮箱邀请与待加入流程)
- 项目预算 (已实现：支持项目 budget_credits 预估与强拦截)
- 成员额度 (已实现)
- 批量封面生成 (已实现)
- 多尺寸导出 (已实现：在无限画布支持导出 SVG/Markdown/JSON)
- 品牌风格提取 (已实现)
- 短视频脚本生成 (已实现)
- 分镜生成 (已实现)
- 模型路由 (已实现：支持质量/成本路由及熔断熔解)
- 任务队列与失败重试 (已实现：Worker 轮询消费与退款结算)
- 成本统计 (已实现：自研毛利与消耗多维度成本报表)
- 无限画布 (已实现：支持选中/层级/复制/删除、文本卡片、一键流输出与多画板)

## P2 功能

P2 是验证商业化后再投入的能力。

- 完整无限画布 (部分已实现，已具备画布增强高级编辑能力)

- 模板市场
- 插件系统
- BYOK
- 私有化部署
- 本地 GPU worker

## MVP 工作流模板

第一版建议只做少量高频模板，不要过早铺开。

### 客户 brief 分析

输入：

- 客户行业
- 产品或服务
- 活动目标
- 目标平台
- 受众
- 参考资料

输出：

- 项目目标总结
- 受众洞察
- 内容方向
- 风格建议
- 风险和限制

### 品牌风格提取

输入：

- logo
- 历史海报
- 社媒截图
- 官网或品牌介绍

输出：

- 色彩倾向
- 字体气质
- 视觉关键词
- 文案口吻
- 可复用 prompt
- 禁用风格

### 三套创意方向

输入：

- 项目 brief
- 品牌库
- 目标平台

输出：

- 方向名称
- 核心概念
- 主视觉描述
- 标题方向
- 适合平台
- 风险提示

### 小红书封面批量生成

输入：

- 主题
- 标题
- 参考图
- 品牌风格
- 数量

输出：

- 多张封面候选
- 标题变体
- 点数消耗
- 可导出素材

### 短视频脚本和分镜

输入：

- 主题
- 时长
- 平台
- 人设
- 产品卖点

输出：

- 开头钩子
- 脚本
- 分镜
- 画面提示词
- 封面标题

## 验收标准

MVP 可以发布的最低标准：

- 用户能在 10 分钟内创建客户、项目和品牌资料。
- 用户能完成至少一种文案任务和一种图片任务。
- 每次生成前能看到点数预估。
- 每次生成后能看到点数流水。
- 项目详情页能用无限画布整理素材卡片和备注。
- 失败任务不会错误扣点。
- 管理员可以配置至少两个上游模型。
- 管理员可以手动补点和查看任务失败原因。

## 暂不做

为了保证第一版能落地，以下能力暂不进入 MVP：

- 完整视频生成平台
- 复杂节点工作流
- 完整无限画布
- 多人实时协作
- 模板市场
- 插件系统
- 私有化部署
- 自研基础大模型
