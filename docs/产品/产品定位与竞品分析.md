# 产品定位与竞品分析

## 产品定位

Reveria 是面向中小型传媒工作室的 AI 创意交付工作台。它关注的不是单次生成，而是从客户 brief、品牌资料、创意方向、图文视频资产、版本修改到最终交付包的完整链路。

中小型传媒工作室的真实痛点通常不是“生成一张图”，而是：

- 多客户、多项目同时推进。
- 每个客户都有固定品牌风格和历史偏好。
- 同一主题需要产出多平台、多尺寸、多版本内容。
- 图、文案、视频、封面、脚本和分镜分散在不同工具中。
- AI 成本不可控，难以计算项目毛利。
- 交付版本、修改意见和素材资产难以复用。

Reveria 的目标是把这些流程收束成一个桌面端工作台。

## 竞品判断

当前市场里，Lovart 更接近 AI 设计 Agent，LibTV 更接近 AI 视频创作工作台。它们都在把创作从单次生成推向多步骤、多模态和 Agent 化。

Reveria 不应该简单复制它们，而应该吸收它们的长处，并把竞争维度提升到传媒工作室的项目交付。

## Lovart 的优势

Lovart 的优势在于把自然语言、设计方向、图像生成、品牌视觉和可编辑画布结合起来。它让用户感觉自己在和一个 AI 设计师协作，而不是在调用单个生图模型。

可借鉴的点：

- 自然语言驱动设计任务。
- 一次生成多个视觉方向。
- 覆盖 logo、海报、社媒图、广告素材和品牌视觉。
- 用 ChatCanvas 承载生成、编辑、整理和迭代。
- 自动路由多个图像与视频模型。
- 用 Brand Kit 保持品牌一致性。
- 用 Skills 把常见任务封装成一键工作流。
- 支持从成功对话沉淀 Custom Skills。
- 支持 PNG、SVG、PSD、PPTX、MP4 等面向交付的格式。

Lovart 给 Reveria 的启发：

- 普通用户需要的是 finished outcomes，而不是一堆工具。
- 画布要服务交付结果，而不是只是展示生成图片。
- 模型选择应该自动化，不能让用户被供应商和参数困住。
- 品牌库必须成为每个项目的默认上下文。
- 成功流程应该能沉淀成可复用模板。

## LibTV 的优势

LibTV 的优势在于面向视频创作链路，把剧本、分镜、图像、视频、多模型和无限画布组织在一起。它更像一个人类创作者和 AI Agent 协作的视频生产平台。

可借鉴的点：

- 从剧本到分镜再到视频的完整链路。
- 用画布承载创意流程，而不是只给线性表单。
- 支持多模型，避免被单一模型能力限制。
- 将专业视频创作拆成可执行步骤。
- 允许人手精修和 AI 自动执行共存。
- 把脚本、分镜、画面、视频、音频抽象为节点。
- 通过角色三视图和多角度锁定提升角色一致性。
- 用多机位分镜提前验证构图、节奏和叙事。
- 使用积分制、会员制、云存储和并行任务作为商业化组合。

LibTV 给 Reveria 的启发：

- 视频不是一个生成按钮，而是一条从策划到成片的生产链。
- 分镜、角色、场景、镜头、配音、字幕都应该是可管理资产。
- 对专业用户可以保留高级工作流入口，但普通工作室用户应该先用模板。
- Agent API 很重要，后续可以让内部自动化或第三方插件调用完整生产流程。
- 积分制需要和模型成本、任务类型、并行能力、存储容量一起设计。

## Reveria 的差异化

Lovart 和 LibTV 的中心仍然是创作工具。Reveria 的中心应该是传媒工作室的项目交付。

Reveria 要做的是：

- 不只生成一张图，而是交付一个客户项目。
- 不只生成一条视频，而是交付一组内容资产。
- 不只关注画布体验，而是关注从 brief 到交付包的完整流程。
- 不只统计模型调用，而是统计项目成本、团队额度和客户毛利。
- 不只记住 prompt，而是记住客户品牌、历史风格和交付偏好。

## 图像精修工作台定位

Reveria 内置的图像精修工作台，不对标 Photoshop、Figma 或 Canva 的大而全设计编辑能力，而是对标**像素蛋糕、泼辣修图、美图秀秀**这类轻量易用的修图产品。

核心方向：
- **人像美化**：磨皮、瘦脸、大眼、美白等高频修饰。
- **色彩调校**：曝光、对比度、饱和度、色温、色调、高光、阴影等专业参数。
- **局部修复**：污点修复、仿制图章、修补画笔，去除画面瑕疵。
- **智能消除**：一键抹除不需要的物体、人物或水印（AI 填充）。
- **抠图与背景替换**：智能抠图，快速换背景。
- **滤镜与预设**：一键风格化，支持自定义预设保存与复用。

这个工作台服务于传媒工作室的素材精修场景——AI 生图后的成品微调、客户交付前的图像润色、批量素材的统一风格处理。它不是独立的修图 App，而是 Reveria 项目交付链路中的最后一公里工具。

详细功能规划见 [图像精修工作台](图像精修工作台.md)。

## 超越方式

Reveria 不应该试图在第一天就让单点图像能力超过 Lovart，或让单点视频能力超过 LibTV。更可行的超越方式是换一个竞争维度：从单次创作体验，升级为工作室生产系统。

核心策略：

- 项目制优先。
- 品牌记忆优先。
- 图文视频一体化。
- 批量生产能力优先。
- 成本和点数控制优先。
- 桌面端、本地素材库和私有化能力优先。
- 管理后台和运营能力优先。

Lovart 是 AI 设计师。
LibTV 是 AI 视频导演。
