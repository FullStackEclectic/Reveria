# 管理后台

## 定位

Admin Console 给平台运营和管理员用，不面向普通创作者。入口是网页端 `/admin`，与工作室工作台共用账号体系。

后台使用邮箱密码或开发登录；系统尚无平台管理员时，第一位成功注册或开发登录的用户会自动成为平台管理员。最后一个平台管理员不能被撤销。

## 当前页面

与 `packages/shared/src/components/admin/AdminView.tsx` 一致，共 7 个 Tab：

| Tab | 能力 |
|-----|------|
| 系统大盘 | 工作区成本报表、任务与点数概览 |
| 算力通道 | 上游服务商、模型目录、启用/禁用、批量导入、文本/生图测通 |
| 套餐管理 | 套餐档位、价格、月度点数、席位与存储配额 |
| 人员管理 | 用户列表、平台管理员授权/撤销、工作区成员与补点 |
| 调度配置 | 工作流模板启用、发布 |
| 提示词模板 | 模板分类与提示词 CRUD |
| 系统设置 | 站点标题、OEM 品牌（域名/Logo/简介/品牌色）、上游网关 URL/Key 与连通测试、注册开关、赠送点数、加价倍率 |

定价规则挂在算力通道/模型侧（`/api/admin/pricing-rules`），没有单独导航页。

## 已有接口但未单独成页

这些能力在 API 或工作台里已有，后台尚未做成独立运营页：

- 全局任务监控与失败重跑
- 审计日志浏览
- 独立模型路由规则页
- 内容安全 / 风控策略配置
- 供应商余额预警

上游 402 会打开全站熔断，系统设置页可「恢复生成」。成本报表接口允许平台管理员或工作区 `owner/admin` 查看，普通成员不能访问。
