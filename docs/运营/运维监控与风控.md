# 运维监控与风控

> **规划文档。** 完整监控栈、告警和内容安全模块尚未按本文落地。当前已有任务状态、成本报表、审计日志表、登录节流，以及上游 402 全站熔断（系统设置可恢复）。

## 目标

Reveria 连接多个上游模型供应商，并采用积分制计费。运维监控和风控的目标是保证服务稳定、成本可控、异常可发现、故障可恢复。

## 核心监控指标

### 业务指标

- 新增用户
- 活跃工作区
- 创建项目数
- 生成任务数
- 点数充值
- 点数消耗
- 任务成功率
- 任务失败率
- 退款率

### 成本指标

- 上游模型成本
- 单任务平均成本
- 单用户平均成本
- 单项目平均成本
- 模型毛利
- 供应商毛利
- 视频任务成本占比

### 技术指标

- API 延迟
- 队列长度
- Worker 数量
- 任务平均等待时间
- 任务平均执行时间
- 上游超时率
- 上游限流率
- fallback 次数
- 存储容量

## 告警规则

建议设置告警：

- 上游供应商连续失败。
- 某模型失败率超过阈值。
- 某用户短时间消耗异常。
- 某工作区点数消耗异常。
- 队列堆积超过阈值。
- 供应商余额不足。
- API key 调用异常。
- 视频任务成本突然升高。
- 退款率突然升高。

## 风控策略

因为上游调用会产生真实成本，风控必须前置。

策略：

- 单用户频率限制。
- 单工作区频率限制。
- 单 IP 频率限制。
- 新用户限制高成本任务。
- 高成本任务二次确认。
- 高风险账户自动冻结。
- 免费额度限制模型等级。
- 异常失败任务自动暂停重试。

## 内容安全

需要根据目标市场选择内容安全策略。

基础能力：

- 输入内容审核
- 输出内容审核
- 敏感词策略
- 图片安全审核
- 视频安全审核
- 违规任务记录

处理方式：

- 拒绝生成
- 修改 prompt
- 降级模型
- 人工复核
- 退款或部分退款

## API key 安全

上游 API key 是高价值资产。

要求：

- 服务端加密存储。
- 管理后台不展示完整 key。
- 修改 key 写入审计日志。
- 支持 key 轮换。
- 支持供应商级限额。
- 支持异常调用告警。

## 故障恢复

常见故障：

- 上游模型不可用
- 上游限流
- 队列堆积
- Worker 崩溃
- 存储上传失败
- 点数结算异常

恢复策略：

- fallback 到备用模型。
- 自动重试。
- 暂停高成本任务。
- 任务状态回滚。
- 点数自动释放。
- 管理员手动重跑。

## 任务重试

重试必须避免重复扣点。

原则：

- 同一个 task_id 重试不重复冻结点数。
- 上游失败重试次数有限。
- 用户主动重试应复用原输入。
- 已成功任务不能重复结算。
- 重试过程写入事件日志。

## 日志和审计

需要记录：

- 用户操作日志
- 管理员操作日志
- 模型调用日志
- 点数流水日志
- 任务状态变更日志
- API key 修改日志
- 退款和补点日志

日志用途：

- 排查故障
- 处理客服问题
- 成本核算
- 风控追踪
- 合规审计

## 客服工具

客服需要能回答用户：

- 为什么扣了点数？
- 任务为什么失败？
- 是否已经退款？
- 用了哪个任务模板？
- 输出在哪里？
- 能不能重跑？

客服后台应展示：

- 用户余额
- 点数流水
- 任务输入摘要
- 任务输出摘要
- 错误原因
- 退款状态
- 手动补点入口
