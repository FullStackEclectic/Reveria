# AdminConsole页面清单

## 定位

Admin Console 是 Reveria 的平台运营后台。它不面向普通创作者，而面向管理员、运营、客服、财务和技术运维。

后台目标：

- 管理上游模型。
- 管理点数和套餐。
- 监控任务和成本。
- 处理退款和补点。
- 发布工作流模板。
- 控制风控和审计。

## 1. 概览页

目标：

- 快速看到平台健康度。

指标：

- 今日任务数
- 今日成功率
- 今日点数消耗
- 今日上游成本
- 今日充值金额
- 当前队列长度
- 异常任务数
- 供应商状态

## 2. 用户与工作区页

目标：

- 管理用户、团队和额度。

功能：

- 搜索用户
- 查看工作区
- 查看余额
- 查看套餐
- 查看任务
- 手动补点
- 手动扣点
- 冻结账户
- 修改成员额度

## 3. 模型供应商页

目标：

- 管理上游模型供应商和 API key。

功能：

- 新增供应商
- 修改 base_url
- 保存 API key
- 启用或禁用
- 设置优先级
- 设置超时
- 设置重试
- 设置限流
- 测试连接

供应商：

- 豆包 / 火山方舟
- Gemini
- Grok
- OpenAI
- Claude
- Azure OpenAI
- MiniMax
- Moonshot
- Qwen

## 4. 模型目录页

目标：

- 维护平台可用模型。

功能：

- 新增模型
- 编辑显示名
- 设置能力标签
- 设置上下文长度
- 设置质量等级
- 设置成本等级
- 启用或禁用

能力标签：

- text
- reasoning
- vision
- image_generation
- image_editing
- video_generation
- audio_generation
- embedding

## 5. 模型路由页

目标：

- 控制不同任务使用哪个模型。

功能：

- 按 task_type 配置主模型
- 配置 fallback
- 配置套餐限制
- 配置地区限制
- 配置成本上限
- 配置灰度路由

示例：

- brief_analysis -> 强推理模型
- xiaohongshu_cover -> 高质量图像模型
- batch_title -> 高性价比中文模型
- storyboard -> 长上下文模型

## 6. 点数与定价页

目标：

- 配置任务扣点规则。

功能：

- 新增 pricing_rule
- 设置 token 计价
- 设置图片计价
- 设置视频秒数计价
- 设置最低点数
- 设置最高点数
- 设置失败退款规则
- 灰度发布价格

## 7. 套餐权益页

目标：

- 管理会员套餐和权益。

功能：

- 新增套餐
- 月度点数
- 额外点数包
- 并发任务数
- 存储容量
- 成员数量
- 品牌库数量
- 高级模型权限
- 视频能力权限
- BYOK 权限

## 8. 任务监控页

目标：

- 查看所有 AI 任务状态。

功能：

- 按状态筛选
- 按模型筛选
- 按供应商筛选
- 按工作区筛选
- 查看输入摘要
- 查看输出摘要
- 查看错误原因
- 手动重跑
- 手动退款

任务字段：

- task_id
- workspace
- user
- project
- task_type
- model
- provider
- estimated_credits
- actual_credits
- provider_cost
- status
- latency

## 9. 工作流模板页

目标：

- 发布和管理业务模板。

功能：

- 创建模板
- 编辑 input_schema
- 编辑 workflow_steps
- 配置模型路由
- 配置点数规则
- 发布版本
- 禁用版本
- 灰度发布
- 查看成功率
- 查看平均成本

## 10. 成本报表页

目标：

- 判断平台是否赚钱。

报表：

- 按供应商成本
- 按模型成本
- 按任务类型成本
- 按工作区毛利
- 按项目毛利
- 退款率
- 失败率
- 平均任务成本

## 11. 风控页

目标：

- 发现和处理异常消耗。

功能：

- 异常用户列表
- 异常工作区列表
- 高频 IP
- 高成本任务告警
- 免费额度滥用
- 自动冻结规则
- 白名单
- 黑名单

## 12. 审计日志页

目标：

- 追踪高风险管理操作。

记录：

- 修改 API key
- 修改定价
- 手动补点
- 手动扣点
- 退款
- 禁用用户
- 删除项目
- 导出数据

## 13. 系统设置页

目标：

- 管理平台级配置。

功能：

- 默认模型路由
- 默认点数规则
- 内容安全策略
- 文件上传限制
- 存储配置
- 通知配置
- 维护模式
