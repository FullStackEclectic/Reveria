## 约定

- 业务数据只存在 Go API。Web 与桌面端不直连数据库。正式环境用 PostgreSQL，本机开发可用 SQLite。
- 实现状态写在对应文档的「当前状态」，不要另开一份平行清单。
- 未做或未立项的内容必须标明，避免被当成现行规格。
