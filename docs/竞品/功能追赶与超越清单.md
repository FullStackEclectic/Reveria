# 功能追赶与超越清单

> **战略对照，不是待办。** 精修、画布、积分、后台等多项已经落地。实现状态看 `TODO.md` 和各产品文档，不要把本文未勾选项当成当前缺口。

## 文档目的

本文件用于回答一个直接问题：

```text
Lovart 和 LibTV 有的关键能力，Reveria 是否也要有？如果要有，怎样做得更好？
```

结论：

- 要有，但不能无脑照搬。
- 要按阶段追赶，而不是第一版全部做完。
- 要把每个功能放回 Reveria 的核心场景：传媒工作室项目交付。
- 要在项目制、品牌记忆、批量交付、积分透明和管理后台上做得更好。

## Lovart 功能追赶

### 1. AI Design Agent

Lovart 能力：

- 用户输入 prompt、参考文件或 Brand Kit。
- Agent 自动选择工具和模型。
- 输出可交付资产，而不是只输出中间结果。

Reveria 必须具备：

- 用自然语言创建项目、分析 brief、生成创意方向。
- 用户不需要先选模型。
- 输出必须直接落到项目里，成为可交付资产。

Reveria 要做得更好：

- Agent 不只理解设计任务，还理解客户、项目预算、品牌历史和交付格式。
- 每次 Agent 行动都能显示预估点数和实际点数。
- Agent 输出必须自动归档到项目、客户和品牌库。

优先级：P0。

### 2. Brand Kit

Lovart 能力：

- Brand Kit 在生成和导出过程中保持品牌一致。
- 品牌上下文可以和 prompt、参考文件一起输入。

Reveria 必须具备：

- 客户级品牌库。
- logo、色板、字体、文案口吻、视觉关键词、禁用词。
- 所有图文视频任务默认读取品牌库。

Reveria 要做得更好：

- 品牌库绑定客户和历史项目，而不是单次设计。
- 自动从历史素材中提取品牌风格。
- 品牌库参与成本统计和项目复盘，例如哪个品牌模板转化最高。

优先级：P0。

### 3. Skills / 一键工作流

Lovart 能力：

- 提供 Branding、Marketing、Social Media、E-Commerce、Video 等 Skills。
- Skill 会封装 prompt、专业设计规则和多步骤模型链。

Reveria 必须具备：

- 工作流模板。
- 客户 brief 分析、品牌风格提取、三套创意方向、小红书封面、短视频脚本和分镜。
- 模板有输入 schema、输出 schema、模型路由和点数规则。

Reveria 要做得更好：

- 模板从 Admin Console 发布和版本管理。
- 每个模板都有成功率、平均成本、退款率和用户反馈。
- 成功项目可以沉淀为客户专属模板或行业模板。

优先级：P0 到 P1。

### 4. Infinite Canvas / ChatCanvas

Lovart 能力：

- 在一个无限画布中生成、编辑、组织图片、视频、音频、品牌资产和 3D 内容。
- 用户可以在聊天和画布之间迭代。

Reveria 必须具备：

- 至少有无限画布或项目结果板。
- 支持结果对比、版本排列、批注、尺寸预览和导出。

Reveria 要做得更好：

- 画布不是单纯创意空间，而是项目交付空间。
- 画布节点关联任务、点数、版本、客户反馈和导出文件。
- 一个画布可以生成完整交付包，而不是只保存视觉探索。

优先级：P1。

### 5. 多模型自动路由

Lovart 能力：

- 自动路由 30+ 图像和视频模型。
- 用户不用学习模型差异。

Reveria 必须具备：

- 管理后台配置上游供应商。
- 模型能力标签。
- 任务级模型路由。
- fallback。

Reveria 要做得更好：

- 路由不仅按效果，还按成本、用户套餐、地区、失败率、项目预算选择。
- 后台展示每个模型的成本、成功率、平均耗时和毛利。
- 用户侧展示任务结果，管理员侧展示模型决策依据。

优先级：P0 到 P1。

### 6. 多格式导出

Lovart 能力：

- 支持 PNG、SVG、PSD、PPTX、MP4 等交付格式。

Reveria 必须具备：

- MVP 至少支持图片和文本导出。
- 后续支持多尺寸图片、MP4、PPTX、PSD、ZIP 交付包。

Reveria 要做得更好：

- 按客户项目一键导出交付包。
- 按平台规格导出，例如小红书、抖音、公众号、视频号。
- 导出包包含素材、文案、脚本、分镜、封面和生成记录。

优先级：P1。

### 7. AI Video Agent

Lovart 能力：

- 从 brief 生成脚本、关键帧和全渠道视频广告。
- 支持文本、图片、音频参考。
- 支持导演级控制，例如镜头运动、节奏、画幅。
- 支持角色一致性、云渲染、渠道比例和变体。

Reveria 必须具备：

- 短视频脚本。
- 分镜。
- 视频封面。
- 视频 brief 分析。
- 后续接入视频生成模型。

Reveria 要做得更好：

- 视频不孤立生成，而是和同一项目的海报、封面、文案、投放标题一起生成。
- 支持客户品牌和历史视频风格。
- 支持项目级视频成本预算和秒级扣点。
- 支持批量生成不同平台的短视频脚本和封面。

优先级：P1 到 P2。

## LibTV 功能追赶

### 1. 无限画布 + 节点工作流

LibTV 能力：

- 以无限画布和节点式工作流为核心。
- 把剧本、分镜、画面、视频、音频和导出流程统一到一个创作引擎。

Reveria 必须具备：

- 后续支持工作流画布。
- 普通用户先使用模板，高级用户和内部运营使用节点。

Reveria 要做得更好：

- 节点不仅表示生成步骤，也表示客户资产、品牌规则、点数成本和交付状态。
- 节点工作流可以发布为普通用户的一键模板。
- 每个节点都能追踪成本、失败率和输出质量。

优先级：P2。

### 2. 剧本到分镜到视频

LibTV 能力：

- 以视频链路为核心，将剧本、分镜、视频片段组织起来。

Reveria 必须具备：

- 脚本生成。
- 分镜生成。
- 镜头描述。
- 画面提示词。
- 封面标题。

Reveria 要做得更好：

- 从客户 brief 同时生成图文和视频资产。
- 分镜自动继承品牌库、产品信息和人物设定。
- 分镜可以反向生成海报、封面和投放文案。

优先级：P1。

### 3. 多参考资产视频生成

LibTV 相关公开资料提到，Seedance 2.0 支持多参考资产输入，包括图片、视频和音频参考。

Reveria 必须具备：

- 项目素材库。
- 参考图上传。
- 后续支持参考视频、参考音频。

Reveria 要做得更好：

- 参考资产按客户、品牌和项目归档。
- 用户可以指定参考资产的作用，例如角色、产品、场景、风格、音色。
- 每个参考资产都可复用于后续项目。

优先级：P1 到 P2。

### 4. 角色一致性

LibTV 能力：

- 强调角色三视图、多角度和一致性控制。

Reveria 必须具备：

- 后续建立角色库。
- 支持人物、产品、场景的固定设定。

Reveria 要做得更好：

- 不只做角色一致，还做品牌一致、产品一致和客户风格一致。
- 角色库和品牌库、项目库联动。
- 同一角色可以生成海报、封面、脚本、分镜和视频。

优先级：P2。

### 5. 30+ 视频模型聚合

LibTV 能力：

- 聚合 30+ 视频模型。
- 公开报道提到 Seedance、Kling、Wan、Vidu、Pixverse 等模型。

Reveria 必须具备：

- 模型网关。
- 视频模型目录。
- 管理后台可配置供应商、模型、价格和开关。

Reveria 要做得更好：

- 不追求模型数量堆叠，追求任务结果、成本透明和可交付。
- 每个模型有质量、速度、成本、失败率和适用任务标签。
- 支持按项目预算自动避开高成本模型。

优先级：P1 到 P2。

### 6. Agent Skill/API

LibTV 能力：

- 公开资料提到 libtv-skills，可让 AI Agent 通过 API 调用视频生成。

Reveria 必须具备：

- workflow_template。
- task API。
- API key。
- 幂等任务。

Reveria 要做得更好：

- Agent API 不只调用视频生成，也能调用客户项目、品牌库、素材库和交付包。
- API 调用同样进入积分账本和风控。
- 插件和 Agent 输出可以直接落到项目里。

优先级：P2。

### 7. 订阅 + 积分 + 并发 + 存储

LibTV 能力：

- 采用订阅和积分制，并将并行任务、云存储、高级能力纳入套餐。

Reveria 必须具备：

- 套餐。
- 点数包。
- 并发限制。
- 存储限制。
- 高级模型权限。

Reveria 要做得更好：

- 给工作室提供项目成本、成员额度和客户毛利。
- 点数消耗可预估、可追溯、失败可退款。
- 管理员能看到模型成本和平台毛利。

优先级：P0 到 P1。

## Reveria 必须追平的功能

P0 必须追平：

- 自然语言任务入口。
- 客户级品牌库。
- 工作流模板。
- 模型网关。
- 点数预估、冻结、结算和退款。
- 生成历史。
- 项目归档。
- 管理后台配置供应商和模型。

P1 必须追平：

- 无限画布。
- 多模型路由和 fallback。
- 批量生成。
- 多格式导出。
- 视频脚本和分镜。
- 模板版本管理。
- 套餐和并发。

第一阶段已落地：

- `xiaohongshu_cover_batch`：批量输出封面标题、副标题、版式、图片生成提示词、反向提示词和设计备注，结果进入项目生成历史。
- `short_video_script_storyboard`：输出 hook、脚本、分镜、画面提示词、口播、屏幕文案和制作备注，结果进入项目生成历史。
- 两个模板都走工作区权限、项目预算、成员日额度、积分扣减和 idempotency 保护。

P2 必须追平：

- 高级画布。
- 节点式工作流。
- 视频生成链路。
- 角色库和场景库。
- Agent/API。
- BYOK。
- 私有化和本地 worker。

## Reveria 必须超越的功能

### 1. 项目制超越

竞品多以创作为中心，Reveria 要以客户项目为中心。

超越标准：

- 每个输出都归属客户、项目和品牌。
- 项目有预算、版本、交付包和成本统计。
- 可以从历史项目复用成功风格。

### 2. 品牌记忆超越

竞品有 Brand Kit，Reveria 要做客户长期记忆。

超越标准：

- 品牌库跨项目长期生效。
- 可从历史素材自动学习。
- 品牌库影响图、文案、脚本、分镜、封面和视频。

### 3. 批量交付超越

竞品强调生成和迭代，Reveria 要强调批量稳定交付。

超越标准：

- 一套创意方向扩展成多平台资产。
- 同一主题生成封面、文案、脚本、分镜和交付包。
- 支持平台尺寸和客户格式预设。

### 4. 积分透明超越

AI 创作工具常见问题是点数消耗不透明。

超越标准：

- 生成前预估。
- 执行中冻结。
- 成功后结算。
- 失败后退款。
- 项目级成本和毛利可见。

### 5. 管理后台超越

竞品前台强，Reveria 要后台强。

超越标准：

- 模型供应商可配置。
- 模型价格可配置。
- 路由规则可配置。
- 模板可发布和回滚。
- 任务、成本、毛利、风控可监控。

## 第一版不要硬拼的功能

为了避免第一版失控，以下功能不要一开始硬拼：

- 完整无限画布。
- 完整节点视频工作流。
- 专业影视级镜头控制。
- 角色三视图和多角度训练。
- 完整 PSD/PPTX 编辑能力。
- 完整 AI 视频成片系统。
- Agent 插件市场。

这些功能要进入路线图，但不能阻塞 MVP。

## 追赶策略

```text
P0：把工作室交付闭环跑通。
P1：补齐画布、批量、多模型路由和导出。
P2：补齐高级视频、节点、Agent/API 和私有化。
```

Reveria 的打法不是先把所有按钮做出来，而是先把“客户项目交付 + 积分成本控制”做成竞品没有明显优势的主战场。
