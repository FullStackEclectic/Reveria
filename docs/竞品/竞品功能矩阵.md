# 竞品功能矩阵

> 战略对照。Reveria 列是产品方向，不是逐项实现状态。

## 对比对象

本矩阵用于帮助 Reveria 判断差异化方向。对比对象：

- Lovart：AI Design Agent。
- LibTV：AI 视频创作工作台。
- Reveria：传媒工作室 AI 创意交付工作台。

## 功能矩阵

| 能力 | Lovart | LibTV | Reveria 应该怎么做 |
| --- | --- | --- | --- |
| 核心定位 | AI 设计 Agent | AI 视频创作工作台 | AI 项目交付工作台 |
| 主要用户 | 设计师、营销人员、创作者、团队 | 视频创作者、短剧团队、Agent 用户 | 中小传媒工作室、代运营团队、内容团队 |
| 入口 | 自然语言 + ChatCanvas + Skills | 无限画布 + 节点 + Agent Skill | 项目 brief + 品牌库 + 工作流模板 |
| 画布 | 强，承载多模态设计资产 | 强，承载视频节点工作流 | MVP 无限画布，后续项目画布 |
| 品牌能力 | Brand Kit | 偏角色和视觉一致性 | 客户级品牌库和长期记忆 |
| 工作流 | Skills / Custom Skills | 节点式视频工作流 | 模板优先，高级工作流后置 |
| 作图 | 强 | 辅助视频流程 | 强，但围绕项目交付和批量 |
| 视频 | 已覆盖视频 Agent | 核心能力 | 从脚本、分镜、封面开始，逐步增强 |
| 多模型 | 自动路由多个图像和视频模型 | 聚合多个图像、视频、语言模型 | 管理后台配置上游，服务端自动路由 |
| 导出 | 多格式导出 | 视频流程导出 | 项目交付包、多平台尺寸、文案和素材打包 |
| 积分/计费 | 有订阅和额度逻辑 | 订阅 + 积分 + 并发 + 存储 | 自研积分账本 + 套餐 + 项目成本 |
| 团队管理 | 公开资料中不是核心差异点 | 公开资料中不是核心差异点 | 工作区、成员、额度、项目预算 |
| 成本毛利 | 未见明确工作室经营中心 | 未见明确工作室经营中心 | 项目毛利、模型成本、成员消耗 |
| 私有化/BYOK | 不是公开核心 | 不是公开核心 | 后续作为企业和工作室高级能力 |
| Agent/API | 设计 Agent 内部体验强 | Skill/API 是亮点 | 后续开放工作流 API 和插件 |

## Reveria 的取长补短

### 从 Lovart 吸收

- Design Agent 交互。
- Chat + Canvas 的协作方式。
- Brand Kit。
- Skills 和 Custom Skills。
- 多模型自动路由。
- 多格式导出。

### 从 LibTV 吸收

- 视频全流程思想。
- 无限画布和节点式工作流。
- 剧本、分镜、角色、镜头的结构化资产。
- Agent Skill/API。
- 订阅 + 积分 + 并发 + 存储的商业设计。

### Reveria 自己要做深

- 客户项目。
- 品牌长期记忆。
- 图文视频一体化。
- 批量交付。
- 项目预算。
- 成员额度。
- 点数账本。
- 成本和毛利。
- Admin Console。
- 桌面端、本地缓存和私有化。

## 我们不抢的第一战场

Reveria 不应该第一版就抢：

- Lovart 的完整设计 Agent 深度。
- LibTV 的完整视频节点工作流。
- 专业影视级视频生成全链路。
- Photoshop/Figma/Canva 式大而全的专业设计编辑能力（图层、矢量、排版等）。

> 图像精修工作台不走 Photoshop 路线，而是对标像素蛋糕、泼辣修图、美图秀秀这类轻量、易用的修图产品——聚焦人像美化、色彩调校、局部修复、智能消除等高频实用功能，不做复杂的专业设计工具。

## 我们要抢的第一战场

Reveria 第一版应该抢：

- 客户 brief 到创意方向。
- 品牌库到图文生成。
- 小红书封面和社媒素材批量生产。
- 短视频脚本和分镜。
- 点数预估、扣减和退款。
- 工作室项目成本统计。
- 管理后台模型和价格配置。

## 差异化口号

```text
Lovart 让你像有一个 AI 设计师。
LibTV 让你像有一个 AI 视频导演。
Reveria 让小工作室像有一个 AI 创意制片团队。
```
